# Changelog

## 1.0.0 — 2026-10-07

- Initial PTDL_v2 release.
- SteamCMD install and branch-aware update wrapper.
- Stable, x86-64, dev, and prerelease branch support.
- 32-bit and 64-bit server binary selection.
- Workshop collection and Workshop auto-update controls.
- Support for the newer `cfg/srcds_workshop_ids.txt` workflow.
- GSLT, map, gamemode, slots, tickrate, hostname, passwords, RCON, location, visibility, LAN, FastDL, loading URL, Lua refresh, P2P, and custom argument settings.
- Safe generated `pterodactyl.cfg` without shell `eval`.
- Preserves custom `server.cfg`.
- Graceful `quit` stop command.
